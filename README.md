# Vibe Coding Platform — Proyecto final · Vibe Coding CEDIA 2026

**Autores:** Francisco Javier Higuera González (Universidad UTE, VC-2026-008) · Carlos Byron Bermeo León (Universidad UTPL, VC-2026-038)

**Guías de proyecto:** Guía 02 (análisis de imágenes con IA) y Guía 18 (actividad interactiva/simulación)

> Narración generada con voz de IA (ElevenLabs) y revisada por los autores.

## Resumen (ES)

Vibe Coding Platform es una plataforma educativa para practicar desarrollo de software y análisis de
imágenes con ayuda de un tutor de inteligencia artificial de iteraciones controladas. Incluye una
actividad interactiva de predicción (distancia = velocidad × tiempo) y un prototipo de conteo de
objetos en imágenes con una regla explícita y detección de imágenes ilegibles. Se verificó con 68
pruebas automatizadas de servidor y 19 de navegador, y se desplegó en un servidor real sin contenedores.

## Summary (EN)

Vibe Coding Platform is an educational platform for practicing software development and image
analysis with the help of an AI tutor with controlled iterations. It includes an interactive
prediction activity (distance = speed × time) and an image object-counting prototype built on an
explicit rule with blur/illegibility detection. It was verified with 68 automated server tests and
19 automated browser tests, and deployed on a real server without containers.
